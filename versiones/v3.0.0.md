# v3.0.0

**Reescritura completa a Python, HTML, CSS y JavaScript. Flask sustituye a NestJS y Jinja2 a Next.js, con las mismas clases Tailwind para que el aspecto no cambie. SQLAlchemy sustituye a Prisma sobre la misma base PostgreSQL, sin migrar ni una tabla. Verificado contra el sistema original: 42 respuestas identicas, 15 pantallas, 9 reglas de negocio y 13 modelos. Corregido un tercer fallo del original: el codigo sugerido para un docente nuevo ya estaba ocupado.**
