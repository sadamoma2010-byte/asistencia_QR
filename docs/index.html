Características principales

Todo lo que necesitas para controlar la asistencia docente de tu institución

Código QR Institucional

Un solo QR para toda la institución. Descargable en PNG y SVG, colocado en el punto de acceso.

Detección Automática de Tardanzas

Calcula puntualidad automáticamente según horarios y tolerancia configurable. Reglas RN007 y RN008.

Reportes Exportables a Excel

Genera informes completos de asistencia y los exporta a Excel con openpyxl para análisis externo.

Seguridad JWT + RBAC

Token de acceso (15 min) y refresco rotativo (7 días). bcrypt con 12 rondas. Permisos granulares por módulo.

PostgreSQL con ORM

16 modelos SQLAlchemy, tipos ENUM nativos, JSONB con índice GIN, búsquedas con ILIKE.

Auditoría Completa

Registra usuario, acción, fecha, IP y dispositivo de cada operación. Evidencia inmutable (RN009).

Flujo del QR Institucional

Un solo código para toda la institución

1

Configurar la dirección

El administrador abre Código QR. La pantalla detecta la dirección del equipo en la red y la propone; basta con guardarla.

2

Generar e imprimir

El sistema genera el QR (descargable en PNG y SVG) apuntando a /marcar. Se imprime y coloca en el punto de acceso.

3

Escanear y entrar

Cualquier docente escanea el QR, entra con su cuenta y el sistema reconoce de quién se trata: cada uno llega a su propia pantalla.

4

Registrar asistencia

Pulsa Registrar entrada o Registrar salida. Se validan las reglas RN001–RN009, se calcula la puntualidad y queda auditado.

Instalación

Requiere Python 3.12+ y PostgreSQL 16+

1 Clonar el repositorio 

git clone https://github.com/sadamoma2010-byte/asistencia_QR.git
cd asistencia_QR

2 Crear entorno virtual e instalar dependencias 

python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

3 Configurar la base de datos 

createdb -U postgres asistencia_qr
psql -U postgres -d asistencia_qr -f database.sql

Escribe la conexión en .env:

DATABASE_URL=postgresql://usuario:contraseña@localhost:5432/asistencia_qr

4 Iniciar la aplicación 

python servidor.py

Aplicación: http://localhost:4000 · API: http://localhost:4000/api/v1
